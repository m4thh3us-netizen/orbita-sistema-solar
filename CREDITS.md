# Créditos

O Órbita usa texturas e dados de terceiros. A mesma lista está em `src/data/creditos.ts`, que a interface exibe. As texturas são geradas por `npm run baixar-texturas` a partir de `src/data/texturas.ts`. Os originais ficam em `.cache/texturas-originais/`, fora do bundle.
